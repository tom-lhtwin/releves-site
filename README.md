# Relevés de site

Outil interne LH Twin (prototype) : plan, photos, stations de scan et avancement du jour sur le terrain, à plusieurs, sans réseau.
Application web statique ; les données restent dans le téléphone de chaque utilisateur.

Projets d'exemple :
- abords du siège, 4 allée de l'Atrium à Claix — photographie aérienne BD ORTHO et BD TOPO © IGN (Géoplateforme, Licence ouverte Etalab 2.0) ;
- poste électrique fictif (plan dessiné, lieu et données inventés).
Les photos des exemples sont des illustrations dessinées.

Lecteur PDF : pdf.js (Mozilla, licence Apache 2.0), dans `vendor/pdfjs/`.
